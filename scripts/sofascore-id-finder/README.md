# Sofascore ID finder

Resolves players the photo crosswalk doesn't cover to their **Sofascore player ID**,
emitting rows ready to paste into `data/sofascore_ids_overrides.csv`.

Companion to [`../sofascore-image-downloader/`](../sofascore-image-downloader/): this
tool finds the IDs, that one fetches the images for them.

## Why this exists

Player photos resolve `transfermarkt_id → sofascore_id → {CDN}/players/{id}.webp`
(`GamePlayer::getImageUrlAttribute`). The `sofascore_id` comes from
`data/sofascore_ids.json`, built from the Reep v0 register — which is **frozen**, while
Reep v1 dropped Sofascore IDs entirely. So the base map can never gain coverage again,
and players it never covered can only be closed out by hand.

That's a lot of hand: on the 2026 dataset, 1,835 of 7,424 players are uncovered, and not
all of them are obscure — Joshua Kimmich is in there. This tool does the lookup for you.

## Why it runs in the browser (and only on sofascore.com)

Sofascore's `/api/v1/...` endpoints 403 any request whose origin/referer isn't
sofascore.com. `curl`, a `file://` page and a fetch from any other site all get 403; the
identical fetch from a tab already on sofascore.com returns 200. Same constraint as the
image downloader, same solution: paste it into the console on a sofascore.com tab.

## How a match is made

Search returns name, club and country but **no date of birth**, so every candidate is
confirmed with a second call to `/api/v1/player/{id}` and accepted **only** when its
`dateOfBirthTimestamp` equals the player's exact date of birth.

Name similarity alone is never enough — football is full of same-name players, and a
wrong ID puts the wrong face on a profile permanently. Anything unconfirmed comes out as
a commented row for a human, never a guess.

Accents are the one fuzziness: Sofascore spells them inconsistently ("Lacine Kone" vs
"Lacine Koné"), so the query is retried with them stripped. The *match* still rests
entirely on the date of birth. Broadening further (surname only) was tried and returns
noise rather than matches, so it deliberately isn't attempted.

Measured on a 15-player sample of the real 2026 gap: **10 confirmed, 5 genuinely absent
from Sofascore.**

## How to run

1. Get the players that need IDs:

   ```bash
   php artisan app:list-unmapped-players --out=unmapped.json
   # or --limit=25 for a trial run first
   ```

2. Open <https://www.sofascore.com> in Chrome.
3. DevTools → **Console** (`⌥⌘J` on macOS). First time only, if Chrome asks: type
   `allow pasting` and press Enter.
4. Paste the entire contents of [`find-ids.js`](./find-ids.js) and press Enter. A panel
   appears top-right.
5. Paste the contents of `unmapped.json` into the textarea and click **Find IDs**.

Start with `--limit=25` to confirm the shape of the results before committing to a full
run. 1,835 players is roughly 5,000 requests — a few minutes at the default settings.

## Options

- **Concurrency** — simultaneous players being resolved (default 3). Deliberately lower
  than the image downloader's 6: this hits an API, not a CDN.
- **Delay (ms)** — pause between a worker's requests (default 150).

## Output

One `sofascore_ids_overrides_additions.csv`, already in the overrides file's format:

```csv
key_transfermarkt,key_sofascore,name
# Generated by scripts/sofascore-id-finder on 2026-09-07.
# 12 confirmed by exact date of birth, 3 unresolved.
161056,111,Joshua Kimmich
#
# --- Unresolved: fill in the middle column by hand and uncomment. ---
# Find the id in the profile URL: sofascore.com/player/{slug}/{id}
# 1371221,,Cheikh Mbacké Diop   (dob 2005-12-29, SK Brann) -- 1 candidate(s), none with matching DOB
```

Confirmed players are live rows; everything else is a `#` comment, which
`app:build-sofascore-id-map` skips. So you can append the whole file to
`data/sofascore_ids_overrides.csv` as-is and work through the leftovers later.

Then:

```bash
php artisan app:build-sofascore-id-map     # fold the overrides into data/sofascore_ids.json
php artisan migrate                        # or re-run the sofascore backfill
```

Newly mapped players still need their image uploaded, or the CDN 404s and they keep the
default avatar — that's what [`../sofascore-image-downloader/`](../sofascore-image-downloader/)
is for.

`__sofascoreIdFinder.lastCsv` holds the last run's output, so you can
`copy(__sofascoreIdFinder.lastCsv)` instead of searching again.

## Tests

`tests/js/sofascore-id-finder.test.js` drives the script in a vm with a stub DOM and stub
fetch. The one that matters most asserts a same-name player with a different date of birth
is **refused**, not written.

```bash
npx vitest run tests/js/sofascore-id-finder.test.js
```
